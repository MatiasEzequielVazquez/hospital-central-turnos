# Hospital Central - Gestion de Turnos

Sistema de consola para registrar, cancelar y atender turnos medicos del Hospital Central,
buscar turnos con filtros y emitir un reporte general con facturacion estimada.

## Requisitos

- Java 17 o superior
- Maven 3.8 o superior

## Ejecucion

```bash
mvn package
java -jar target/hospital-central-turnos-1.0.0.jar
```
